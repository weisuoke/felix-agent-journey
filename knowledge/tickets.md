# 练习知识库：工单处理规则

本文描述本地练习环境。工单真实保存在 SQLite 中，但不会发送到外部客服系统。

## 创建工单

工单必须有非空标题和问题描述。问题描述应说明现象、发生时间和已经尝试的排查。缺少关键信息时先追问，不猜测。

创建前必须由用户在终端核对完整内容，并输入 APPROVE。用户在聊天中要求创建不等于程序已经获得审批。非交互终端不允许写入。

## 查询工单

查询使用正整数工单 ID。数据库不存在该 ID 时必须明确告知不存在，不能编造状态。

## 重复请求

一个 request_id 对应一个工单。相同 ID 和相同内容重复提交返回原工单；同一个 ID 用于不同内容时拒绝操作。换 ID 会视为新的请求。

## 处理状态

新建工单默认状态是 open。当前工具只支持创建和读取，不支持关闭工单、退款、解锁账号或发送邮件。
